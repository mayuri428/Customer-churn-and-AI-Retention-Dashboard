# Customer Churn & AI Retention Dashboard

An end-to-end data analytics and machine learning pipeline integrated with PostgreSQL and an interactive Power BI dashboard.

# Project Overview
Retaining existing customers is far more cost-effective than acquiring new ones. This project connects backend customer data and predictive Machine Learning outputs directly into an executive Power BI report. 

Business managers can use this dashboard to identify high-risk customer accounts and execute targeted retention protocols.


##  Tech Stack & Tools
* **Programming Language:** Python (VS Code)
* **Database:** PostgreSQL, SQL
* **Business Intelligence:** Power BI Desktop
* **Core Concepts:** Predictive Analytics, Churn Segmentation, Dashboard UI/UX Design


##  Key Features
* **ML Model Integration:** Python script to process raw customer data and calculate churn probabilities.
* **Database Pipeline:** Direct connection between PostgreSQL database views and Power BI.
* **Predictive Analytics:** Categorizes customer accounts into segmented **Risk Levels** (`Low`, `Medium`, `High`).
* **Actionable Retention Plans:** Maps automated **AI Retention Plans** directly to high-risk customer profiles.
* **Executive Table Layout:** Designed for scannability and quick decision-making.

##  Files Included
* `.pbix` - Power BI Dashboard File
* `.py` - Python script for data processing and prediction
* `.sql` - SQL queries and database view creation scripts
